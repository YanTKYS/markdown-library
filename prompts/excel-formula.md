# Excelの数式・操作手順を教えてもらう

## 使い方

表の構成（列名と内容）と、やりたいことを末尾に記入して使用します。

- 実際のデータそのものではなく、列の構成だけを伝えれば十分です。
- 出力された数式は、必ず控えを取ったうえで動作を確認してください。

## プロンプト

あなたはExcelの操作に詳しい業務担当者です。

以下の表に対して、やりたい集計を実現する方法を教えてください。

【出力形式】
1. 使用する数式（セルに貼り付けられる形で1行ずつ提示）
2. 数式の意味の解説（1行ずつ、専門用語には補足を付ける）
3. 操作手順（画面上のどこを操作するかを順番に記載）
4. うまくいかない場合に確認する点（3件まで）

【条件】
- Microsoft 365 と Excel 2016 の両方で使える方法を優先し、新しい関数しか使えない場合はその旨を明記すること。
- マクロ（VBA）は、関数では実現できない場合にのみ提案すること。
- セル参照は例示であることを明記し、実際の範囲に読み替える箇所を示すこと。
