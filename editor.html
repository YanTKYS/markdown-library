Markdownエディタ

タイトルやカテゴリなどの設定（front matter）を手書きせずに、Markdown の作成・編集を行うための支援ツールです。

このツールは Markdown の作成・編集を支援するだけです。GitHub や公開サーバへの反映は行いません。 生成した Markdown をダウンロードし、entries/ フォルダへ配置したうえで、 data/manifest.json にファイル名を登録してください（詳しい手順は README.md を参照）。
ローカルの .md ファイルを直接開く（上級者向け）

編集

一覧と詳細画面の見出しになります。30字程度まで。

カテゴリ必須

data/tags.json 内の定義から1つだけ選べます。分類の追加・変更は管理側の作業です。

タグ任意

data/tags.json 内の定義から複数選択できます。分類の追加・変更は管理側の作業です。

一覧に表示される1行の説明です。40字程度まで。

入力した内容がそのまま本文として保存されます。見出し（#）・箇条書き（- / 1.）・太字（**）・コード（`）・コードブロック（```言語名）が使えます。

生成AIへ渡す文面や PlantUML などのコードは、```text や ```plantuml で囲むと、閲覧画面でブロックごとにコピーできます。

末尾は「.md」にしてください。日本語も使えます。\ / : * ? " < > | や制御文字、Windows の予約名（CON・PRN・NUL など）は使用できません。

プレビュー

保存

必須項目（タイトル・カテゴリ・説明・本文・保存ファイル名）をすべて入力すると、ダウンロードできます。

保存後、entries/ フォルダへ配置し、data/manifest.json の entries 配列に次の行を追加してください。
