# 糸の交点：守る規則・調整してよい点・避ける実装

出典：design-lab の9番目の比較デザイン `okinawa-thread`（比較サイト本体の CSS / JS と、独立した3画面の試作）。ここには再現に必要な核だけをまとめた。色の値は [../assets/tokens.css](../assets/tokens.css) を正とする。

## 着想と説明のしかた

- 宮古上布で経糸・緯糸を使い、方眼に十字絣を割り付けるという**工程の考え方**から、短い縦横線の交点・格子・縦横の軸という**独自の図形**に翻訳した。
- 説明するときは「宮古上布に着想した独自のデザイン（仮称：糸の交点）」とする。公式の意匠、伝統工芸の再現、沖縄全域の代表様式とは言わない。
- 実在の織物の図柄・写真・型紙は取り込まない。模様は基本図形（短い十字）から作る。

## 必ず守る規則

| 規則 | 内容 |
| --- | --- |
| 地と面 | 本文の地は濃藍（`--ot-ground`）。入力欄は明るい無地（`--ot-input`）で、文字は濃い藍（`--ot-input-text`）。条件や行の区切りは**面の色ではなく罫**で示す。 |
| 格子帯 | 本文の左端に、細い縦横の格子の帯（幅 16px 前後。狭い幅では 8px 前後）を通す。全画面で同じ位置に置き、同じシステムだと分かるようにする。 |
| 章 | 章の上に二重の横罫。章見出しは明朝（端末にあれば）で、前に小さな交点の印。章の中は「章見出し｜項目名｜値」の縦軸で区切る。 |
| 読み順 | 一覧は「識別子（番号）→ 状態 → 内容の値」の順に固定し、番号・状態の右に縦軸を1本通す。詳細は選んだ行の直下に、同じ「項目名｜値」の軸で差し込む。 |
| 操作の階層 | 主操作は生成りの塗り（`--ot-cream`）に濃藍の文字で、文言は動詞（「保存する」「確認へ」）。副操作は細い枠。クリアや移動は下線の文字。 |
| 選択とフォーカス | 選択は生成りの塗り＋チェック＋太字。フォーカスは黄色の外枠（`--ot-focus`）と濃藍の間隔で、選択とは別の色と形にする。プログラムで移したフォーカスにも枠を出す。 |
| エラー | 欄の太枠（`--ot-error-line`）、「エラー」の文字と理由・直し方（`--ot-error`）。件数と項目名のまとめを先頭に置き、項目名から該当欄へ移れる。装飾の色をエラーに使わない。 |
| 集計 | 指標はカードを並べず「指標名 → 値 → 定義 → 一覧へのリンク」の行にする。先頭の総数だけ明るい行（`--ot-lead`）にしてよい。推移は横棒で、件数を棒の端に文字で添える。リンクにできない値（率など）はリンクにしない。 |
| 狭い幅 | 600px 未満では項目名を値の直上に置き、表は行ごとにラベル付きで縦に読む。ページ全体を横にはみ出させない。 |
| 装飾 | 十字の模様は見出し面の右端だけ。`aria-hidden="true"`。情報・操作の上に重ねない。グラフや表の領域に模様を敷かない。 |

## 調整してよい点

- **画面の部品**：対象の業務にない部品は作らない。メモなら「番号→状態→件名」、予約なら「日時→状態→利用者」のように、識別子と状態にあたる列を業務に合わせて選ぶ。
- **章の数と名前**：業務の区切りに合わせる。章が1つしかない小さな画面では、二重罫と格子帯だけでもよい。
- **幅**：章見出しの欄（PC で 180〜200px）、項目名の欄（160〜180px）、外余白（PC 52px／中間 24px／狭い幅 16px）は、内容に合わせて調整してよい。
- **見出し面と模様**：小さな画面では見出し面を低くし、模様を省いてもよい（格子帯と二重罫は残す）。
- **状態の色**：状態ごとの色は、文字・アイコン・枠の形とセットで使う。色の数は減らしてよい。
- **書体**：明朝がない環境ではゴシックでよい。外部フォントは読み込まない。

## 避ける実装

- design-lab の CSS・HTML・JS（比較サイト専用の `main.js`、`data-action` 規約など）を丸ごと持ち込む。
- 濃藍に塗っただけのダークテーマで、格子帯・二重罫・項目軸がない。
- 同じ大きさのカードを並べる指標、影・グラデーションの多用。
- 選択とフォーカスを同じ色だけで示す。エラーを色だけで示す。
- 模様を背景全体に敷く、本文や入力欄の背後に置く、読み上げ対象にする。
- 対象アプリのデータ・保存処理・検証・ルーティングを、見た目の都合で変える。
- 外部のフォント・CDN・API を追加する。

## 確認の観点

- 背景と文字、入力欄の文字、補助文字の読みやすさ（濃藍の地では補助文字が暗くなりすぎやすい）。
- 長い日本語（法人名、手続き名、同意文）の折り返しと、375px でのページ全体の横はみ出し。
- IME 変換中の入力・検索、キーボードでの主要操作、開閉後のフォーカスの戻り先。
- 色だけに頼らない状態表示（文字・チェック・枠・アイコン）。
- 明朝・ゴシックのどちらでも崩れないこと（端末に明朝がない場合）。
